Esta lista contém exercícios em JavaScript para praticar lógica de programação e conceitos fundamentais de linguagem. Utilizaremos a biblioteca prompt-sync para entrada de dados no terminal. Para isso, siga as seguintes instruções:

- abrir terminal integrado
- digitar npm install prompt-sync
- rodar terminal para instalar prompt-sync node.js.
- requisitar dados no arquivo com const prompt = require('prompt-sync')();
